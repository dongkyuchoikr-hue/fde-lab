# 이번 주 미국 주식 해설 — 조건에 맞는 종목 5개와 지난주 복기 · 주경야독 2026 개인 학습 프로젝트

사이트: https://dongkyuchoikr-hue.github.io/fde-lab/
데이터: 다우존스 30종목의 공개 일별 시세(수정 종가 · 공급자 EODHD · 이용 조건 원문과 공개 범위 결정은 [docs/data/README.md](docs/data/README.md)) · 이용 조건이 가격 데이터의 '표시'를 금지하므로 화면에는 가격 숫자 대신 **순위·조건 결과·방향만** 공개 · 원본 일별 시세는 공개 저장소·화면에 올리지 않음(비공개 작업 폴더와 재시도용 Actions 캐시에만, 최대 7일) · 종목 목록은 위키백과 DJIA 구성표(CC BY-SA 4.0) · 키는 Actions Secret 에만 · 내 보유 종목·금액 없음 · 투자 조언 아님 · 기준일(ET·KST)·규칙 버전·공개 범위는 화면에 표시

## 무엇을 하는가
미국 주식 초보가 · 다우 30종목이 이번 주 어떻게 움직였는지 표로 보고 · **미리 공개한 규칙**(조건 4개: 데이터 충분 · 200일 추세선 위 · 이번 주 +10% 급등 아님 · 최근 4주 −7% 급락 없음 → 점수: 추세 40 · 잔잔함 40 · 낙폭 20 → 상위 5, 같은 업종 최대 2개)에 가장 잘 맞는 5종목을 한국어 이유 3줄·위험 표시와 함께 보고 · 지난주 고른 5종목이 실제로 어땠는지(순위 대상 종목 평균·시장 SPY 대비, 가정 매매 비용을 뺀 뒤에도 나았는지 참/거짓)와 규칙이 고른 교훈 한 줄을 매주 기록으로 돌아본다.

하지 않는 것: 수익 예측 · 매수/매도 권유 · 목표가 · 비중·금액 제안 · 11월 AI 호출(모든 문장은 규칙 템플릿) · 백테스트 · 규칙 튜닝(규칙 v1 은 2026-11-09 확정, 바꾸면 v2 로 새 기록) · 표시 권리가 확인되지 않은 데이터의 숫자 공개 · 내 실제 보유 종목·금액 공개.
「조건에 맞는 종목」은 과거 가격 숫자가 규칙에 맞았다는 뜻이지 오를 종목이라는 뜻이 아닙니다. 기록은 26주 미만이면 읽지 말고, 26주가 지나도 1년 남짓한 기록으로는 규칙이 좋은지 판단하기 어렵습니다 — 그래서 틀린 주도 그대로 보여 줍니다.

## 어떻게 돌아가는가
1. 토요일 12:17 KST — `fetch-prices.yml` 이 31종목(다우 30 + SPY)의 일별 시세를 받아(비공개 작업 폴더) 주간 통계 → 지난주 결과 → 이번 주 선정을 계산하고, 검사를 통과하면 `docs/data/` 만 봇 커밋 + 태그 `data/{기준일}` → `check-deploy.yml` 호출 → Pages 배포 → 배포된 기준일 확인. 일요일 09:47 KST 재시도, 월요일 09:30 KST 마지막 확인(이미 최신이면 아무것도 하지 않음 · 그때까지 금요일 행이 없으면 실행이 빨간불로 끝남).
2. 화면(`docs/index.html`)은 `weekly.json`·`picks.json`·`results/`·`track_record.json` 을 읽어 그립니다. 파일이 없거나 깨지면 그 절만 「데이터 없음 — 이유」로 보이고 기준일·고지 문구는 항상 보입니다.
3. 규칙·종목 목록·휴장일·공급자 결정은 JSON 네 개로 공개돼 있고(`docs/data/`), 지난 선정·결과·기록은 추가만 하며 바꾸면 검사가 실패합니다.

## 처음 보는 사람이 여는 법
(회차 4·8에서 실제로 해 본 뒤 고칩니다 — 작동하지 않는 순서를 완성된 안내처럼 남기지 않습니다)
1. 이 저장소를 fork 합니다 → Actions 탭에서 워크플로를 켭니다(fork 는 꺼진 채 시작)
2. Settings → Pages → Source: GitHub Actions
3. EODHD 무료 키를 만들어 Settings → Secrets and variables → Actions → `EOD_API_KEY` 로 넣습니다. 키가 없으면 fetch-prices 는 첫 단계에서 실패합니다(demo 키는 벤치마크 SPY 를 주지 않아 계산할 수 없음). 키 없이 화면만 보려면 Actions → check-deploy → Run workflow 로 저장소에 이미 커밋된 자료를 배포합니다. 또 Settings → Actions → General → Fork pull request workflows 에서 "Require approval for all outside collaborators" 를 켭니다(원본 시세 캐시를 다른 워크플로 실행이 읽지 못하게)
4. Actions → fetch-prices → Run workflow (main) — 끝나면 check-deploy 가 이어서 배포합니다
5. 1~2분 뒤 https://<내 계정>.github.io/<저장소>/ 를 엽니다. 숫자 버전 예시는 `?data=fixtures`
